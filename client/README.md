# SMMS Flutter Cross-Platform Client

Client application (Mobile & Web) for field maintenance engineers and infrastructure asset managers in Tanzania.

## Features (Phase 3 Roadmap)
1. **Real-time Structural Health Dashboard**: Visual gauges for bridge/building vibration, strain, and displacement.
2. **Field Camera Crack Inspection**: Capture high-resolution concrete photos and run immediate CNN edge/cloud classification.
3. **GIS Asset Condition Mapping**: Map visualization of monitored infrastructure corridors across Dar es Salaam, Dodoma, Arusha, and Mwanza.
4. **Maintenance Work Orders & Approvals**: IDSS priority-ranked intervention list with digital sign-off.
5. **Offline Synchronization**: Local SQLite storage for remote infrastructure sites with limited cellular coverage.
